# Üçüncü Taraf Bildirimi

BLOCKVERSE – Ultimate Edition kaynak ağacında **harici lisanslı görsel, ses, model veya font varlığı bulunmaz**.

- Tüm dokular `scripts/core/texture_factory.gd` ile çalışma zamanında prosedürel üretilir.
- Tüm sesler `scripts/core/audio_library.gd` ile çalışma zamanında sentezlenir.
- Karakterler, düşmanlar, silahlar ve yapılar `scripts/entities/character_rig.gd` ve ilgili sistemlerle prosedürel geometriden oluşturulur.
- Proje, Godot Engine 4.7.2-stable (MIT lisanslı, https://godotengine.org) ile geliştirilmiştir. Godot kaynak kodu bu depoya dahil değildir; yalnızca proje dosyaları bulunur.
- Minecraft ve Roblox bu projede kullanılan bir varlık, marka veya API değildir; oyun mekanikleri bağımsız olarak tasarlanmıştır.
- Export şablonları ve Android SDK, derleme sırasında GitHub Actions tarafından geçici olarak indirilir; depoya eklenmez.
